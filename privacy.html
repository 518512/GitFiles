隐私政策

最后更新：2026 年 6 月 6 日

GitFiles（https://mbaigc.github.io/GitFiles/）是一个浏览器文件管理器， 由 MbAIGC 维护，是基于 Mykhailo Mikus 的 Storage Hub 修改的分支项目。它可以访问本地存储以及 GitHub 仓库。 本政策说明应用处理哪些信息以及处理方式。

开发者信息

GitFiles 是一个由 MbAIGC 维护的开源项目，基于 Storage Hub（原作者： Mykhailo Mikus）。 本项目不隶属于 Google LLC，也未获得其认可或赞助。

摘要

  • 本地存储主要在浏览器中运行；GitHub 仓库功能通过同源 Cloudflare Worker 处理 OAuth 会话与 GitHub API 请求。
  • GitHub OAuth 访问令牌仅保存在 Worker 的 HttpOnly 会话和 D1 会话存储中，不会返回给浏览器或写入浏览器存储。
  • 本地存储元数据及界面偏好会保存在你的浏览器中。
  • 我们不会出售你的个人信息。

我们访问的信息

当你使用 GitHub 登录并同意权限请求时，应用仅访问展示和操作你有权限的仓库所需的信息：

  • GitHub 返回的账户标识和仓库权限信息。
  • 浏览文件夹、打开文件、创建或编辑项目以及执行你发起的操作所需的 GitHub 文件和元数据。

当你使用 GitHub 登录时，GitHub OAuth 授权码会发送到配置的 Worker。Worker 会将访问令牌保存在 D1 会话记录中，并根据 GitHub 返回的仓库权限建立会话访问控制列表。

信息用途

通过 Google API 或 GitHub API 访问的信息仅用于提供应用功能，包括：

  • 展示你的云端文件、文件夹和已授权的 GitHub 仓库；
  • 执行你主动发起的导航、查看、搜索、创建、编辑、移动、复制和删除操作；
  • 在同一浏览器中支持多个 Google 账号以及挂载多个本地存储或 GitHub 仓库；
  • 在内置记事本中打开支持的文本文件。

数据存储位置

  • 你的 Google Drive 或 GitHub 仓库：文件仍由对应服务保存，除非你通过应用或服务本身修改或删除它们。
  • 你的浏览器：Google 会话令牌、已登录用户列表、本地存储元数据和界面偏好可能保存在设备浏览器的本地存储中。GitHub 访问令牌不保存在浏览器。
  • Cloudflare Worker 与 D1：GitHub 会话令牌、登录名、过期时间以及仓库访问控制信息用于完成同源 API 请求和权限检查。
  • Service Worker 缓存：HTML、CSS、JavaScript、图标和其他应用外壳文件可能被缓存以支持离线加载；缓存不会包含 Google Drive 或 GitHub 文件内容，也不会缓存 `/api/` 响应。

清除网站数据、退出 Google 账号，或退出 GitHub 会话，会移除该应用可移除的本地或服务器端会话信息。

我们不会收集的内容

  • 我们不会建立用于销售或分析的用户资料数据库或文件内容数据库。
  • 我们不会收到你的 Google 或 GitHub 密码。
  • 应用不运行第三方广告或分析跟踪器。

第三方服务

应用会与以下服务通信：

  • Google Identity Services（登录）
  • Google Drive API
  • GitHub OAuth 和 Git Data API
  • Cloudflare Workers 与 D1（同源 API、会话和访问控制）

Google 对信息的使用受其隐私政策约束。

GitHub 对信息的使用受其隐私声明约束。Cloudflare 可能按照其服务条款和隐私政策处理技术连接数据。

数据保留

浏览器中的 Google 会话信息和偏好会保留到你退出、移除账号或清除该站点存储为止。GitHub Worker 会话会在过期后失效；退出 GitHub 会话会清除对应 Cookie 和服务器端会话记录。文件内容仍由 Google Drive 或 GitHub 按其自身规则保留。

安全

应用通过 HTTPS 与 Google、GitHub 和 Worker API 通信。GitHub 访问令牌仅在 Worker 侧使用，并通过 HttpOnly、Secure、SameSite Cookie 关联浏览器会话。你仍应负责保护使用应用的设备和浏览器；请勿在共享或不受信任的设备上处理敏感数据。

儿童隐私

本应用不面向 13 岁以下儿童，我们不会故意收集儿童的个人信息。

你的选择

  • 你可以随时在 Google 账号权限页面撤销应用访问权限。
  • 你可以在 GitHub 账号设置中撤销 GitFiles 的 OAuth 授权。
  • 你可以在应用中退出单个 Google 用户、退出 GitHub 会话或移除所有已挂载存储。
  • 你可以随时停止使用应用。

政策变更

我们可能不时更新本隐私政策。页面顶部的“最后更新”日期会反映最新版本。政策变更后继续使用应用，即表示你接受更新后的政策。
