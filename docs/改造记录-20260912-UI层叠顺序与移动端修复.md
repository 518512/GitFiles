# 改造记录 20260912 UI 层叠顺序与移动端布局修复

## 修改了什么

### 1. 根因：CSS 层叠顺序被反转（这是「笨拙」的主因）

`js/base-path.js` 的 `bootstrapHeadAssets()` 用 `appendChild` 动态注入 `style.css`，
而 `index.html` 里静态写的是 `ui-v2.css`。两者结合导致实际层叠顺序变成：

```text
ui-v2.css（设计令牌 / V2 覆盖）  ← 先加载，被覆盖
style.css（3400 行历史样式，21 处 !important） ← 后加载，最终生效
```

也就是说**整个 V2 设计系统一直被历史样式压住**。历次「界面: 收敛添加按钮 / 缩小按钮 /
对齐工具按钮」的提交之所以反复回退，就是因为在 `ui-v2.css` 里加规则根本赢不了
`style.css` 的 `!important` 与更高特异性。

修复：

- `index.html` / `notepad.html` / `404.html` 三个页面统一为
  `style.css` → `ui-v2.css` 的静态书写顺序（消除首屏 FOUC）。
- `bootstrapHeadAssets()` 改为只负责给两个 link 补 `?v=APP_VERSION` 与 base path，
  并在末尾**重新追加** `ui-v2.css`，保证无论 HTML 怎么写，V2 都最后层叠。
- 版本号用 `scripts/bump-cache.js` 提升，Service Worker 自动清理旧缓存。

### 2. `ui-v2.css` 结构性重写

原文件存在**三个互相打架的 `.ribbon` 块**和**两个重叠的 `@media (max-width:768px)`**，
后写的块覆盖先写的块，是「补丁叠补丁」的典型形态。现按编号小节重写：
设计令牌 / 顶栏 / 主区域侧栏 / 列表 / 仓库页 / 概览页 / 桌面 / 移动端。

### 3. 移动端不再隐藏关键控件

原移动端规则直接 `display: none` 掉排序、视图切换与面包屑，等于**砍掉功能**换空间。
现改为独立的两行布局：

```text
第 1 行  导航开关 · 品牌 · [弹性] · 刷新 · 添加
第 2 行  面包屑（横向滚动）· 搜索 · 视图切换
```

仅排序控件在小屏收起，其余保留；所有可点元素按 `--tap-target: 44px` 统一到 ≥44px。

### 4. 视觉密度

- 顶栏高度 56 → 52px，列表行高 48 → 44px，侧栏导航项 40 → 36px（移动端仍强制 44px）。
- 新增 `--color-border-muted` / `--color-accent-subtle` 令牌，替换散落的 `#eaeef2`、`#ddf4ff` 硬编码。
- 仓库页、概览页间距整体收紧，去掉重复的 `margin-left: auto` 与冗余 `box-shadow: none`。

## 为什么改

用户反馈「感觉很笨拙」。经排查，并不是缺少设计，而是**设计层根本没生效**：
V2 规则被历史样式压制，于是只能在 V2 文件里不断加更强的补丁，越补越乱。
先修正层叠顺序，再清理重复块，最后才谈具体视觉参数。

## 涉及文件

```text
js/base-path.js       CSS link 注入改为保序 + 追加 V2
index.html            静态声明两层样式表
notepad.html          补齐样式表（此前完全依赖 JS 注入，首屏无样式）
404.html              补齐 data 属性与版本号逻辑
css/ui-v2.css         按小节重写，消除重复 .ribbon 与重叠媒体查询
js/app-version.js     版本号提升（由 scripts/bump-cache.js 生成）
```
