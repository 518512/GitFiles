# 改造记录：首页访问与 PWA 样式

## 修改了什么

- PWA 安装入口移动到左侧“添加存储”下方，并统一与添加存储按钮的宽度、内边距和高度。
- 安装按钮文案调整为“点击安装 GitFiles -PWA”。
- 未认证访问 `/index.html` 时默认直接进入文件管理界面，本地存储无需 GitHub 登录。
- 首页“添加仓库”和侧栏 GitHub 仓库入口继续执行 Worker 会话认证门禁，未认证不会直接进入仓库选择或创建流程。
- 登录状态和初始化期间不再先显示登录页，避免刷新时出现短暂的 1～2 秒引导页闪烁。

## 测试情况

- JavaScript 语法检查通过。
- Git 引擎 35 项测试通过。
- Worker API 13 项测试通过。
- 构建和 `git diff --check` 通过。

## 遗留问题

浏览器已经缓存旧 HTML 时，首次部署后可能需要强制刷新一次以加载新的首页结构；Service Worker 更新后会自动清理旧缓存。
