# 全屏 GitHub 风格界面改造

## 修改了什么

- 将主应用从居中的 Windows 风格窗口改为全屏工作区。
- 移除应用背景渐变、最大宽度限制、外层留白和窗口阴影。
- 顶部标题栏改为 GitHub 风格深色导航栏。
- 工具栏、地址栏、面包屑、侧边栏、文件列表和状态栏统一采用 GitHub 风格中性色与蓝色交互色。
- 降低圆角和装饰性阴影，提高文件管理场景的信息密度。
- 保留现有左侧仓库树；移动端继续使用抽屉式侧栏和遮罩层。
- 移动端保留 40px 以上工具按钮、滚动面包屑和紧凑文件网格。
- 更新 `APP_VERSION`，使 Service Worker 和带版本号的样式资源失效并重新加载。

## 为什么改

原界面仍以桌面窗口为中心，使用渐变背景和最大 1100px 容器，不符合全屏文件管理器和 GitHub Web 的使用习惯。此次改造保持现有 DOM 与功能入口不变，仅统一视觉和空间布局，降低迁移风险。

## 涉及文件

- `css/style.css`
- `js/app-version.js`

## 遗留问题
