# 改造记录：PWA 按钮响应修复

## 修改了什么

- 修复 PWA 安装事件在页面头部提前触发、但应用脚本尚未绑定监听器时导致按钮状态不同步的问题。
- 页面头部捕获 `beforeinstallprompt` 后派发 `gitfiles:install-ready` 事件，应用加载完成后立即更新安装按钮状态。
- `updateInstallUi()` 会从全局安装事件缓存恢复提示对象，避免按钮看似可用但点击无动作。
- 安装提示增加取消和异常反馈；浏览器不支持自动安装提示时，按钮会显示 Edge 菜单中的手动安装路径。
- 安装完成后仍会隐藏按钮并显示已安装状态。

## 为什么改

PWA 的 `beforeinstallprompt` 由浏览器决定触发时间。此前事件可能在 `App.bindEvents()` 执行前触发，虽然对象保存在全局变量中，但界面没有收到状态更新，造成按钮无响应或状态错误。
