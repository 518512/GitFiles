# 改造记录：Logo 透明背景与画布适配

## 修改了什么

- 使用重新上传的 `new_logo.png` 重新处理 Logo。
- 去除接近白色的背景和中性灰背面阴影。
- 保留透明 Alpha 通道，避免 Logo 在不同背景下出现方形底色或阴影。
- 识别主体内容边界后裁剪空白区域，并按比例缩放到约 94% 画布范围。
- 保持宽高比，不对 Logo 进行拉伸变形。
- 重新生成应用 Logo、PWA 图标和 favicon 的全部尺寸。
- 更新 Service Worker 应用版本，确保客户端淘汰旧 Logo 缓存。
