# 改造记录：Markdown 预览修复

## 修改了什么

- 扩展 GitHub、本地存储和兼容路径的文本文件识别范围。
- 支持 `.md`、`.markdown`、`.txt`、`.csv`、`.log`、配置文件和常见源代码文件进入记事本预览/编辑流程。
- 修正 GitHub 文件名推断 MIME 类型，Markdown 和代码文件按 `text/plain` 处理。
- 修正独立记事本页面的路径解析，确保 `/仓库/My Drive/docs/readme.md` 能解析到 GitHub 文件。
- 更新旧的“仅支持 txt/json”错误提示。

## 为什么改

UI 调整后，文件打开仍依赖原有的文本识别逻辑；该逻辑只识别 `.txt` 和 `.json`，导致 Markdown 被当作普通二进制文件下载。独立记事本页面还使用已移除 Google Drive 兼容层的空路径解析函数，导致新标签页无法定位 GitHub 文件。

## 涉及文件

`js/githubdisk.js`、`js/localdisk.js`、`js/drive.js`、`js/notepad.js`。

当前“预览”使用文本编辑器打开 Markdown，尚未提供渲染后的 Markdown 安全预览模式。HTML/SVG 等文件仍按现有浏览器查看策略处理。
