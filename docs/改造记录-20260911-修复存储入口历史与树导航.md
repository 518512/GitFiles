# 改造记录：修复存储入口、历史与树导航

## 修改了什么

- 删除地址栏中无用途的当前位置链接复制图标和对应事件。
- 删除顶部黑色圆点账户占位控件及其无效提示行为。
- 修复顶部和概览页“添加存储”入口：统一阻止全局菜单关闭事件冒泡，再显示本地存储/GitHub 仓库选择菜单。
- 增加 `GithubDisk.listHistory()`，通过既有 Worker `GET /api/repos/:owner/:repo/history` 获取当前分支最近 30 条提交。
- 将仓库“历史”标签从禁用占位改为真实可切换视图，支持刷新提交记录。
- 顶部添加存储按钮在桌面显示完整文字、在窄屏显示加号，不再截断。
- 将侧栏导航开关移到 GitFiles 品牌左侧。
- 压缩侧栏文件树行高、缩进和留白，并为目录和文件补上类型图标。

## 为什么改

UI V2 第一阶段留下了多个没有完整业务接入的控件：添加存储菜单被全局点击监听立刻关闭，历史标签被禁用，黑色账户点和地址栏复制图标没有足够产品价值。侧栏树的行距和缺少图标也降低了浏览效率。

## 涉及文件

`index.html`、`js/app.js`、`js/githubdisk.js`、`css/ui-v2.css`。

## 测试情况

- JavaScript 语法检查。
- Git 引擎和 Worker API 回归测试。
- 静态构建与 `git diff --check`。

## 遗留问题

- 历史视图当前只显示最近 30 条提交，不提供分页和提交详情页。
- 本地存储没有 Git 历史，历史标签只在 GitHub 仓库中可用。
- Repository Picker 仍沿用统一的添加存储菜单和 Dialog。
