## 背景

用户指出 `GITHUB_CLIENT_ID` 与 `CONFIG_GITHUB_CLIENT_ID` 在 README 中容易混淆。

## 命名现状（不改名的原因）

- `CONFIG_*`（CONFIG_GITHUB_CLIENT_ID 等）：**构建时**由 scripts/build-config.mjs
  消费，注入前端 CONFIG；前缀同时避开 GitHub Actions 保留的 `GITHUB_` 开头
- `GITHUB_CLIENT_SECRET`（无前缀）：**运行时**由 Worker（workers/entry.js）消费，
  命名遵循 GitHub OAuth 生态惯例
- 用户已完成配置，改名是 breaking change 且无收益

## 修改了什么

双语 README「配置 Client ID」章节新增「部署变量速查表」：五个环境变量的
名称 / Cloudflare 类型（Text vs Secret）/ 消费阶段 / 作用 / 与前端键名的对应关系，
并写明命名规则（CONFIG_* = 构建时 Text；无前缀 = 运行时 Worker）。
