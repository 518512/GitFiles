# 改造记录：对齐添加存储工具按钮

## 修改了什么

- 将顶部添加存储按钮从蓝色主操作样式改为与刷新按钮同级的透明工具按钮。
- 默认移除蓝色背景、白色文字和实线边框。
- 对齐周边工具控件的 32px 尺寸、4px 圆角、17px 图标字号和悬浮反馈。
- 保留标题、无障碍标签和原有添加存储菜单逻辑。

## 为什么改

添加存储是工具栏操作，不是页面提交操作。此前即使缩小尺寸，蓝色背景仍然使其视觉权重远高于 GitFiles 品牌、仓库状态和刷新控件，比例不协调。

`css/ui-v2.css`。
