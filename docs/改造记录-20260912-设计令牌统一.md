# 改造记录 20260912 设计令牌统一（D 层：--win-* → --color-*）

## 背景

用户要求处理 style.css 的第 D 层：统一双轨变量体系。

此前项目存在**两套设计令牌**：

```text
style.css   --win-*    Windows 风格：灰蓝 #0078d4 系（171 处使用）
ui-v2.css   --color-*  GitHub 风格：主应用使用
```

style.css 不是死文件——它是**登录页、记事本、对话框、属性面板、法律页**的
样式来源（这些页面要么只加载 style.css，要么 ui-v2 未覆盖其关键类）。
因此"统一"不能靠删文件，只能靠**变量值归一**。

## 做了什么

### 1. `--win-*` 全部改为引用 `--color-*`

```css
:root {
  --win-blue:       var(--color-accent);       /* 原 #0078d4 */
  --win-blue-dark:  var(--color-accent-dark);  /* 原 #005a9e */
  --win-bg:         var(--color-bg);           /* 原 #f3f3f3 */
  --win-border:     var(--color-border);       /* 原 #d1d1d1 */
  --win-hover:      var(--color-hover);        /* 原 #e5f3ff */
  --win-selected:   var(--color-selected);     /* 原 #cce8ff */
  --win-text:       var(--color-text);         /* 原 #1a1a1a */
  --win-text-muted: var(--color-muted);        /* 原 #616161 */
  --title-bar-bg:   var(--color-surface);      /* 原 #f9f9f9 */
  --sidebar-bg:     var(--color-bg);           /* 原 #f9f9f9 */
}
```

- 171 处 `var(--win-*)` 引用**无需改动**，值自动跟随主应用配色
- 每个旧值都写在注释里，**回退 = 还原这一块**即可
- `--shadow`（0 8px 32px，弹窗阴影）不是配色，独立保留；
  ui-v2 的 `--shadow-sm` 是另一种极轻阴影，两者不混

### 2. 补齐 `--color-*` 缺失令牌

ui-v2.css 的 `--color-*` 体系原来没有：accent-dark / hover / selected。
已补（GitHub 风格取值），供 `--win-blue-dark` / `--win-hover` / `--win-selected` 引用。

### 3. 关键：style.css 单独加载的页面也能解析

`privacy.html` / `terms.html` / `github-oauth-callback.html` **只加载 style.css**。
若 `--color-*` 只定义在 ui-v2.css，这些页面的 `--win-*` 会解析失败（页面失配）。

因此把 `--color-*` 基础令牌**同时内联进 style.css 的 `:root`**。
ui-v2.css 重复定义同名变量，值相同、无冲突；只加载 style.css 的页面也能解析。

### 4. body 背景统一

`body { background: #eef2f6 }` 硬编码，与 `--color-bg: #f6f8fa` 不一致，
改为 `var(--color-bg)`。其余局部意图色（`#fff`、`#fde7e9` 警示色等）保持不动。

## 影响（必须知晓）

**这是视觉变更，不是纯重构**：

- 登录页、记事本、对话框、属性面板、隐私/条款页
  会从 Windows 灰蓝（#0078d4）切到 GitHub 风格（#0969da 蓝、#f6f8fa 背景）
- 这**正是"统一"的目的**：此前主应用是 GitHub 风、独立页面是 Windows 风，
  风格分裂
- 数值大多接近（文本 #1a1a1a→#1f2328、背景 #f3f3f3→#f6f8fa），
  差异明显的是主色 #0078d4 → #0969da（主应用早已用新蓝）

若对某个页面的配色不满意，可单独在 style.css 该页选择器上覆盖，而不是回退整个 D 层。

## 涉及文件

```text
css/style.css    :root 令牌统一 + 内联 --color-* 基础令牌 + body 背景
css/ui-v2.css    补 --color-accent-dark / --color-hover / --color-selected
```
