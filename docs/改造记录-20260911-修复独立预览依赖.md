# 改造记录：修复独立预览依赖

## 修改了什么

- 为 `notepad.html` 补充 `js/auth.js`，修复 `Notepad.initStandalone()` 启动时缺少 `Auth` 导致页面初始化中止的问题。
- 将 `auth.js` 和 `drive.js` 加入 Service Worker 的应用壳缓存清单。
- 递增应用版本，强制旧 Service Worker 清理缓存并重新加载最新脚本。

## 为什么改

主界面双击文本文件会在新标签页打开 `notepad.html`。该页面加载 `notepad.js` 前没有加载 `auth.js`，但 `notepad.js` 的独立页面初始化和兼容路径分支仍引用 `Auth`。因此页面会在启动阶段抛出 `Auth is not defined`，Markdown 等文件无法打开。

## 涉及文件

`notepad.html`、`sw.js`、`js/app-version.js`。

## 测试情况

- 检查独立页面脚本加载顺序：`storage-migrate -> auth -> drive -> localdisk -> github-api -> github-paths -> githubdisk -> dialog -> notepad`
- 检查 Service Worker 应用壳包含 `auth.js`、`drive.js`
- 运行 JavaScript 语法检查和现有 Worker/Git 引擎测试

## 遗留问题

Markdown 当前以文本编辑器方式打开，还没有渲染后的安全 Markdown 预览模式。
