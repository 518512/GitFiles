# 改造记录：严格认证访问控制

## 修改了什么

- 恢复未认证访问控制：访问 `/index.html` 或其他应用入口时，未完成 GitHub Worker 会话认证只能看到登录页面。
- 文件管理器在 HTML 初始状态保持隐藏，避免未认证用户直接看到文件区、添加仓库入口或其他应用内容。
- 增加全屏启动验证遮罩，在会话检查完成前不展示登录页或文件管理器，避免刷新时短暂闪现错误页面。
- 会话验证成功后才显示文件管理器；失败后只显示 GitHub 登录页。
- 保留本地安装按钮样式和 PWA 入口，不改变认证边界。
