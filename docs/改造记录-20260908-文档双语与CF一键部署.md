## 修改了什么

### 1. 新增项目协作规范（`AGENTS.md` §33）

- 每次代码改动必须在 `docs/` 生成中文命名的改造记录（`改造记录-YYYYMMDD-主题.md`），含修改内容/原因/文件/测试/遗留问题
- Commit message 一律使用中文（`类型: 摘要`）
- `README.md`（中文主文档）与 `README_EN.md`（英文）必须同步变更
- 本仓库禁止向上游 `fi3ik-mme/storage-hub` 提 PR / Push，只推 `origin`

### 2. README 中文化美化 + 英文同步

- `README.md` 全文重写为中文主文档，按项目实际情况组织：徽章（在线地址 / Cloudflare 一键部署 / 测试状态 / 上游）、功能特性、快速开始、部署（Cloudflare Pages + GitHub Pages + 三种 token 代理对照）、测试、架构图、模块职责、目录结构、与上游差异表、已知限制、致谢
- 删除过时的上游作者运维记录（MishaMikusEleks 域名、Search Console 品牌验证全流程等）；Google OAuth 配置精简为必要步骤
- 新增 `README_EN.md` 英文同步版（保留 OAuth 注册表单用的应用描述文案）

### 3. Cloudflare 一键部署

- 新增 `wrangler.jsonc`：Pages 配置（`pages_build_output_dir: "."` 纯静态、`404-page` 兜底、无构建步骤），注释说明 `GITHUB_CLIENT_SECRET` 配置方式
- 新增 `functions/api/github/oauth/token.js`：OAuth token 交换 Pages Function（对应 PROJECT_SPEC §20 的迁移路径），逻辑与 `serve.py` 代理一致：
  - `client_id === 'reachability-check'` → 直接返回 JSON（前端可达性探测）
  - 请求体自带 `client_secret` → 原样转发
  - 其余注入 env secret（`GITHUB_CLIENT_SECRET`，可选 `GITHUB_CLIENT_ID` 覆盖），缺失返回 `misconfigured_proxy`
  - CORS 仅放行 `*.pages.dev` 与 localhost；`OPTIONS` 204
- README.md / README_EN.md 加入官方 Deploy to Cloudflare 按钮（`deploy.workers.cloudflare.com/?url=...`）

### 4. 无用文件清理

- 删除 `scripts/publish-storage-hub.sh`（上游作者迁移脚本，硬编码无关账号与 `.git_key`）
- 删除 `scripts/search-console-report.sh`（上游 Search Console 专用，硬编码上游域名与项目号）
