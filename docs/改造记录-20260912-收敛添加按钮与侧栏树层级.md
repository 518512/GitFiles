# 改造记录：收敛添加按钮与侧栏树层级

## 修改了什么

- 顶部“添加存储”改为纯加号图标按钮，保留标题和 `aria-label`。
- 桌面端按钮尺寸调整为 32px × 32px；移动端调整为 36px × 36px。
- 左侧本地存储和 GitHub 仓库树移除重复的“文件”中间层。
- 展开一个库后直接显示其根目录的文件夹与文件；本地存储的“回收站”作为独立额外入口保留。
- 点击库的展开箭头时直接加载根目录树，避免必须先打开库页面才能显示内容。
- 删除不再生成的 GitHub “文件”层导航解析逻辑。
- 同步更新主入口与 404 回退入口的添加按钮 DOM。

## 为什么改

“文件”层级只重复表达了库根目录，增加一行、一级缩进和一次点击，不帮助用户理解结构。顶部添加按钮在上一版虽已缩小，但文字主按钮仍与紧凑工具栏不协调。

## 涉及文件

`index.html`、`404.html`、`js/app.js`、`css/ui-v2.css`。

## 测试情况

- JavaScript 语法检查。
- Git 引擎和 Worker API 回归测试。
- 静态构建、主入口和 404 入口标记同步检查、`git diff --check`。

## 遗留问题

- 本地存储仍保留回收站入口；GitHub Repository 不存在等价回收站。
- 文件树继续使用现有按需加载和分页机制。
