# 改造记录：补充 fork 用户一键部署链接说明

- 日期：2026-09-08
- 关联：`docs/改造记录-20260908-修复CF部署路径.md`

## 修改了什么

双语 README「Deploy to Cloudflare 按钮（备选）」章节新增说明：

- 按钮链接格式：`https://deploy.workers.cloudflare.com/?url=<仓库地址>`
- fork 用户应把链接中的仓库地址替换为自己 fork 的地址
- 点击他人 README 的按钮也可用（Cloudflare 引导授权后使用用户自己账号下的仓库副本部署），但部署源不是用户自己的 fork，后续 push 自动构建不会跟随
- 重申按钮为备选路径，主推 Git 连接（方式一）

## 为什么改

用户询问 fork 用户的一键部署链接是否仍是 `?url=https://github.com/MbAIGC/GitFiles`。需要澄清：链接指向的是"被部署的仓库"，fork 用户应替换为自己的 fork 地址，否则部署源与后续 Git 集成脱离其仓库。
