# 改造记录：跨设备仓库同步

## 修改了什么

- GitHub 登录成功后，自动调用 `GET /api/repos` 获取当前账号可访问的仓库。
- 将返回的仓库元数据同步到当前设备的本地挂载列表。
- `upsertDiskFromRepo` 同时兼容 Worker 返回的 `{ owner, repo }` 数据和 GitHub 原始仓库对象。
- 继续只保存仓库元数据，不保存 GitHub access token。

## 为什么改

此前 GitHub 仓库挂载信息只保存在浏览器 `localStorage`。同一 GitHub 账号在另一台设备登录后虽然拥有有效 HttpOnly 会话，但本地挂载列表为空，因此看不到第一台设备上的仓库。仓库内容实际在 GitHub 中，设备间需要同步的是仓库挂载元数据。

## 涉及文件

`js/app.js`、`js/githubdisk.js`。

## 测试情况

- JavaScript 语法检查通过。
- Git 引擎测试和 Worker/API 测试通过。
- 构建产物检查通过。
- `git diff --check` 通过。

## 遗留问题

当前仓库挂载元数据仍保存在每台设备本地；登录后会从 Worker/GitHub 重新发现可访问仓库。设备特有的分支选择不会跨设备同步。
