# 改造记录：PWA 安装入口

## 修改了什么

- 在登录页增加“安装 GitFiles”按钮。
- 监听 `beforeinstallprompt`，在浏览器确认满足安装条件后显示安装入口。
- 监听 `appinstalled`，安装完成后更新提示。
- 已安装为独立应用时隐藏安装按钮并显示已安装状态。
- 增加 Android/iOS 安装相关提示元数据的配套说明。

## 使用方式

使用 HTTPS 或 localhost 打开 GitFiles，等待 Service Worker 注册完成；Chrome/Edge 判断可安装后会显示“安装 GitFiles”按钮。Android Chrome 也可通过菜单“添加到主屏幕”；iOS Safari 使用“分享 → 添加到主屏幕”。

## 测试情况

- `node --check js/app.js` 通过。
- `node --check js/register-sw.js` 通过。
- Git 引擎 35 项测试通过。
- Worker API 13 项测试通过。
- 构建和 `git diff --check` 通过。

## 遗留问题

浏览器只有在 HTTPS/localhost、Manifest 有效、Service Worker 已控制页面且满足用户参与度等条件后才会触发 `beforeinstallprompt`；不满足时按钮不会显示，仍可使用浏览器菜单手动安装。
