# 改造记录：全面 UI 优化

## 修改了什么

- 增加统一的应用状态条，承载认证、离线、错误和操作反馈。
- 增加当前目录搜索、名称/时间/大小/类型排序及升降序切换。
- 增加 Ctrl/Command/Shift 多选状态和移动端固定选择操作栏。
- GitHub 多选删除复用批量删除 API，避免逐项提交。
- 移动端搜索、排序和选择操作达到 40px 以上触控尺寸，并适配安全区域。
- GitHub 侧栏显示 `owner/repo · branch`，方便区分同名仓库。
- 保持 Breadcrumb 横向滚动和现有 Bottom Sheet/长按菜单行为。
- 收敛页面背景颜色，减少大面积渐变，统一工作台视觉。
- 切换目录时自动清除搜索和选择状态，避免产生“文件消失”的错觉。

## 为什么改

原界面已有桌面右键菜单和基础移动端抽屉，但搜索、排序、多选和持久状态反馈不足；GitHub 仓库只显示短名称，多个仓库时难以区分。此次改造聚焦重复使用场景和移动端可发现性，同时保持现有 Git 操作与权限边界。

## 涉及文件

`index.html`、`css/style.css`、`js/app.js`。

## 遗留问题

- 复制/移动多选仍建议使用现有批量上下文菜单，选择栏当前只直接执行 GitHub 多选删除。
- 真实 Android 长按、虚拟键盘和不同浏览器的 PWA 安装流程仍需设备验收。
- 冲突中心仍是现有对话式 UI，三方 diff/合并属于独立功能阶段。
