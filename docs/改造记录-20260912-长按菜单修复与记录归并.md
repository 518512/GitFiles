## 一、长按菜单两个缺陷

用户真机反馈：移动端长按弹出的菜单**无法选中就消失**；**关闭按钮显示有问题**。

### 1. 菜单在选中前消失

**根因**：`js/contextmenu.js` 里有一个 **capture 阶段**的滚动关闭监听：

```js
window.addEventListener('scroll', hide, true);   // ← capture
```

移动端菜单是底部 bottom sheet（`.context-menu--sheet`），
其选项列表 `.ctx-sheet-body` 是 `overflow-y: auto` 的滚动容器。

用户在 sheet 内**滑动选择**或手指微动时，会先产生 `scroll` 事件；
capture 阶段让它**先于 `click`** 到达，直接调用 `hide()`——
菜单在点击生效前就消失了。

**修复**：滚动关闭时排除菜单自身的内部滚动，只有背景/列表真的滚动才收起：

```js
window.addEventListener('scroll', (e) => {
  const target = e.target;
  // 菜单内部滚动不应关闭菜单
  if (target instanceof Element && target.closest('#context-menu')) return;
  hide();
}, true);
```

### 2. 关闭按钮显示有问题

`.ctx-sheet-close` 是 36×36 的圆形按钮，依赖父级布局居中 `✕` 字形，
位置与大小不稳定；且 36px **低于移动端主要操作的 44px 触达下限**
（`PROJECT_SPEC` §7.1）。

**修复**：

```css
.ctx-sheet-close {
  width: 44px; height: 44px;          /* 触达下限 */
  display: inline-flex; align-items: center; justify-content: center;
  font-size: 1.05rem; line-height: 1; padding: 0;
  color: #1f2328;                      /* 显式前景色，此前可能继承异常 */
  -webkit-appearance: none; appearance: none;
}
```

### 排查过程（记录一下排除项）

先确认了**不是**这些原因，避免误改：

```text
✗ longPressFired 状态残留 —— touchend 只 clearPress()，但下一次 touchstart 会复位
✗ click 命中按钮后冒泡到 document 关闭 —— 按钮有 stopPropagation，且 document
  监听器本身也检查 closest('#context-menu')
✗ backdrop 抢走点击 —— backdrop 与菜单是兄弟节点，z-index 999 < 1001
✓ capture 阶段 scroll 监听（上述根因）
```
