# 改造记录：审查任务单 T1-T5 修复（P0 全清 + 跨仓库批量化 + 部署收口）

- 日期：2026-09-08
- 关联：`docs/代码审查-20260908-main系统审查与修复任务单.md`

## 修改了什么

1. **T1（P0-2）token 会话缓存**：`acquireAccessToken()` 模块级缓存已验证 token
   （getAuthenticatedUser 校验），登录 → 创建/连接仓库等连续调用只弹一次授权。
   涉及 `js/githubdisk.js`。
2. **T2（P0-1）仓库生命周期重设计**：新增 `ensureGithubStorage()` 统一入口
   （Dialog.choose：Connect existing repository ∥ Create new repository (Drive-N)）；
   登录（app.js signInWithGithub）与 Add storage → GitHub repo（contextmenu
   createGithubDisk）均改走该入口 —— 不再强制创建 Drive-1；创建失败自动降级
   Connect 表单（保留 resolveRepositoryForDisk 原降级）。`connectExistingRepository`
   升为一级可达。
3. **T3（P0-3）token 过期处理**：apiRequest 对 401/403 抛错附带 `tokenExpired`
   标记；新增 `reauthorizeDisk(diskId)`（刷新盘 token + 账号信息）；GitHub 盘
   右键菜单新增 "Re-authorize"。
4. **T4（P1-1/P1-2）跨仓库/跨存储批量化**：githubdisk 新增
   `collectGithubItems`（只读递归收集，空目录记 mkdir）、`createBatchFromCollected`
   （目标仓库单 commit 写入）、`deleteBatch`（源仓库单 commit 前缀删除）；
   contextmenu：GitHub→GitHub 跨仓库 copy = 目标 1 commit（cut 时源 +1）；
   local/Google→GitHub 同模式（collectLocalIntoBatch/collectGoogleIntoBatch）。
   N 文件跨仓库 copy 从 ≈2N+ 目录数 commits 降为 1（cut 时 2）。
5. **T5（P1-3）GitHub Pages 部署收口**：pages.yml 增加 setup-node +
   `node scripts/build-config.mjs`（`${{ vars.* }}` 透传 CONFIG_*），upload path
   改 `./public`（不再整仓公开）；README 双语同步说明 Actions Variables 注入通道。

session）为独立里程碑，本轮不动。
