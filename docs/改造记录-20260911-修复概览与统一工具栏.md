# 改造记录：修复概览与统一工具栏

## 修改了什么

- 将“概览”从复用文件网格的首页状态改为独立工作区面板。
- 概览显示 GitHub 仓库、本地存储和已挂载存储总数，并列出可直接打开的已挂载存储。
- “仓库”导航只进入已挂载 GitHub 仓库的文件工作区；概览和仓库不再显示同一内容。
- 将原先新增的 App Header 和原有 Ribbon 合并为一条统一工作区工具栏，保留返回、路径、搜索、排序、视图切换、添加存储与账户状态等原有功能。
- 修复 Sidebar 工作区导航的点击事件和活动状态刷新。
- 补齐 Repository Header 和概览面板的桌面、移动端样式。

## 为什么改

UI V2 第一阶段只新增了“概览”和“仓库”的视觉入口，但首页仍将挂载存储当作普通文件网格渲染，两个入口实际行为近似；同时 Header 与 Ribbon 分列两行，浪费垂直空间并增加了状态不同步风险。

## 涉及文件

`index.html`、`js/app.js`、`css/ui-v2.css`。

## 测试情况

- JavaScript 语法检查。
- Git 引擎和 Worker API 回归测试。
- 静态构建、PWA 资源清单和 `git diff --check` 检查。

## 遗留问题

- “仓库”当前打开第一个已挂载仓库；后续可扩展为独立 Repository Picker。
- History 和分支选择仍未提供完整独立视图。
- 旧 `style.css` 仍保留历史样式，未在本次功能回归修复中做大规模删除。
