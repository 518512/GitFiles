# 改造记录：登录 / 落地页改版（参照 deepseek.com）

> 日期：2026-09-18 · 范围：`index.html`、`404.html`、`css/style.css`
> 目标：把「认证登录首页」的视觉参照从 GitHub 卡片式登录框，改为 deepseek.com
> 那种**极简落地页**（柔和浅底 + 居中大标题 + 胶囊按钮），并去掉与产品无关的模块。

## 1. 修改了什么

### 1.1 视觉参照与取舍

先抓取了 deepseek.com 的公开样式，提取出可直接复用的设计令牌（不是凭印象模仿）：

```text
页面底色      #f9f8f8          文字主色   #152443（蓝黑）
品牌蓝        #4d6bfe          链接蓝     #234792（浅底上更易读的那个）
卡片/面板圆角  24px / 16px      胶囊      100px
毛玻璃        blur(12px)       主按钮底   #1a1615（近黑）
Slogan        38→42px / weight 400 / line-height 155% / opacity .92
容器宽        min(100% - 48px, 1140px)
字体          system-ui … "Noto Sans SC","PingFang SC"
```

**保留**：顶部极简导航、居中大标题、副标题、主/次行动按钮、署名、法律入口。
**去掉**（用户明确要求 + 与产品无关）：对话输入框、新闻横幅、产品/研究/加入我们
等营销分栏、APP 二维码、社交图标。

### 1.2 标记结构（index.html / 404.html 保持一致）

```text
#login-screen.login-screen
├── header.landing-nav        品牌（logo + GitFiles）｜源码 / 隐私政策 / 服务条款
├── main.landing-hero
│   ├── p.landing-eyebrow     「MbAIGC 出品」胶囊
│   ├── h1.landing-slogan     把 GitHub 仓库 / 当作云端文件系统
│   ├── p.landing-sub         一句话说明
│   ├── div.landing-actions   #btn-sign-in-github（深色胶囊）+ 查看源码（毛玻璃胶囊）
│   └── p#login-error         role="alert"
└── footer.landing-foot       p.login-about（署名与致谢）
```

- 保留 JS 依赖的全部钩子：`#login-screen`、`#btn-sign-in-github`、`.btn-label`、
  `#login-error`。`js/app.js` 的 `showLogin` / `showLoginError` / `setSignInBusy`
  无需改动。
- 404.html 与 index.html 使用**同一份**结构，避免两处漂移。

### 1.3 样式（写入 V2 覆盖层）

新增规则全部放在 `css/style.css` 末尾的 V2 覆盖层，并给 `.login-screen` 定义
**页面局部令牌**（`--landing-*`），不污染全局 GitHub 风格令牌；应用内其余界面
保持原样。

同时删除了三代历史登录样式，避免继续叠加：

```text
历史层第一代   .login-screen / .login-card / .login-logo / .login-brand /
               .login-card h1 / .login-card p / .login-about / .btn-github /
               .login-error
历史层第二代   .login-screen / .login-card / .btn-primary,.btn-github 共享圆角
               .login-footer*
移动端         .login-card { … }
```

（`.btn-primary` 与 `[aria-busy]` 旋转仍保留——前者服务于应用内按钮，后者是登录
按钮的加载态。）

### 1.4 细节打磨

- `.app-boot`（首屏「正在验证访问权限…」）底色改为与落地页同色，避免闪一下另一种灰。
- 署名里的链接改用 `#234792`（DeepSeek 浅底链接色）以满足小字号对比度；品牌蓝
  `#4d6bfe` 只用于光晕等装饰。
- 触摸目标：主/次按钮 48px；导航链接桌面 40px、窄屏 44px。
- `min-height: 100dvh` + `env(safe-area-inset-*)`，适配移动端地址栏与安全区。
- `@media (prefers-reduced-motion: reduce)` 关闭过渡。
- 窄屏（≤560px）：行动按钮竖排撑满，"源码"链接隐藏，内边距收紧。

## 2. 为什么这样改

- 原登录页是一个 420px 的白色卡片 + 阴影，视觉上是「GitHub 时代的登录框」；
  用户希望首屏更像 deepseek.com 的落地页，因此改为整屏留白 + 居中大标题的
  落地页结构，并把品牌/法律入口收敛到顶部导航。
- 只做**页面级**的主题，不把 DeepSeek 的配色扩散到应用内——应用其余部分仍按
  `AGENTS.md §14` 保持 GitHub 风格（低圆角、高密度、低装饰）。
- 顺手清掉三代历史登录样式：这正是审阅报告 R-13 指出的「历史层多代叠加」问题，
  既然要重做这一块，就不该再叠第四代。

## 5. 遗留问题

- **未做浏览器/Android 截图验证**（本环境没有可用的无头浏览器）。需要按
  `状态总览` P-11 在真机上确认：桌面与窄屏的标题换行、按钮竖排、导航链接触达、
  iOS 安全区、以及首屏光晕在 OLED/低亮度下是否过重。
- 落地页目前只有浅色主题；应用本身也没有深色主题，因此未做 `prefers-color-scheme`
  分支。若后续引入深色主题，`.login-screen` 的局部令牌就是唯一需要覆盖的地方。
- 首屏光晕是 `radial-gradient`，与 `AGENTS.md §14`「避免大面积渐变」有张力，
  但这是用户明确要求模仿的落地页观感，且强度很低（10% → 3% → 透明）。
  若真机上觉得重，改 `background-image` 一处即可。
- 未给落地页加载 `DM Sans` 等自定义字体（避免新增外部依赖与字体请求），
  使用系统字体栈，观感接近但不完全等同 deepseek.com。
