# 改造记录：一键部署项目名修正为 gitfiles

- 日期：2026-09-08
- 关联文件：`wrangler.jsonc`、`README.md`、`README_EN.md`

## 修改了什么

- `wrangler.jsonc` 的 `name` 由 `storage-hub` 改为 `gitfiles`（Pages 项目名规则：仅小写字母、数字、连字符，域名相应为 `https://gitfiles.pages.dev`）
- 注释强化：说明一键部署向导会预填该 `name`、改名后需同步更新 GitHub OAuth App 的 callback URL
- 双语 README 的一键部署段落同步：明确项目名默认值来源、可改、改名后回调地址要跟着改

## 为什么改

用户反馈：通过 Deploy to Cloudflare 按钮部署后，Pages 项目名是 `storage-hub` 而非 `GitFiles`。原因是向导的项目名默认读自 `wrangler.jsonc` 的 `name` 字段，之前沿用了上游的命名。

## 已有部署的处理（给用户的操作指引）

- 若已存在 `storage-hub` 项目：Dashboard 删除该项目后重新走一键部署（将读到新 name）；或在向导中手动把项目名改为 `gitfiles`
- 项目名/域名变更后，GitHub OAuth App 的 Authorization callback URL 需改为 `https://gitfiles.pages.dev/github-oauth-callback.html`

## 涉及文件

- `wrangler.jsonc`（name 字段与注释）
- `README.md` / `README_EN.md`（一键部署说明）

- 用户侧需按上述指引处理已创建的 `storage-hub` 项目（仓库内无法代劳）
