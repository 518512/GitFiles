# 中文化、登录提速与 GitHub 永久删除改造记录

## 修改了什么

- 将登录页、文件管理器、菜单、对话框、记事本、协议页和 OAuth 回调页面的主要可见文案统一为简体中文。
- 保留全屏、低圆角、高密度的 GitHub 风格文件管理器布局，并补充登录按钮即时加载状态与旋转提示。
- GitHub OAuth 登录关键路径不再执行额外的可达性探测和登录后重复 `/api/me` 请求。
- Worker 登录阶段只创建会话；仓库权限列表改为首次访问 `/api/repos` 时按需发现并批量写入 D1，降低登录等待时间。
- GitHub 仓库删除直接调用 Git Data 删除流程并创建提交，不进入回收站；确认文案明确提示永久删除且不可撤销。
- 进度预计时间改用中文单位显示。

## 为什么改

之前登录流程包含不必要的网络往返，且登录时提前分页获取仓库列表，网络较慢时会明显延迟。界面仍有较多英文动态提示，导致中文用户理解成本较高。GitHub 仓库没有可恢复的回收站语义，因此删除操作必须明确使用 Git Tree 删除并提交历史。
