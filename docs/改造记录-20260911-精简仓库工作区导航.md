# 改造记录：精简仓库工作区导航

## 修改了什么

- 删除统一工具栏中的后退、前进、向上三级文件管理器导航按钮。
- 删除仅服务于这三个控件的前端导航函数、绑定和按钮状态更新代码。
- 保留刷新、路径面包屑、侧栏仓库树和浏览器自身的前进/后退能力。

## 为什么改

GitFiles 的核心工作流是 Repository Workspace。后退、前进、向上三个文件管理器式按钮占用紧凑工具栏空间，且与路径面包屑、仓库树导航重复，实际价值较低。

## 涉及文件

`index.html`、`js/app.js`。

## 测试情况

- 静态构建与 `git diff --check`。

## 遗留问题
