# 改造记录：移动端显示搜索并保留刷新

## 修改了什么

- 移动端显示当前目录搜索框。
- 移动端保留刷新按钮，并将其放在搜索框左侧。
- 移动端隐藏路径面包屑、排序控件和网格/列表切换控件，避免挤压搜索输入区域。
- 保留顶部导航开关、GitFiles 品牌和添加存储入口。
- 桌面端继续保留路径面包屑、当前目录搜索、排序和视图切换。

## 为什么改

移动端搜索是文件浏览的必要功能。路径、排序和视图切换与搜索同时出现会挤压输入区域，因此移动端用“刷新 + 搜索框”的紧凑第二行承载高频文件浏览操作。

## 涉及文件

`css/ui-v2.css`。
