# 改造记录：移除无效路径图标

## 修改了什么

- 删除主入口和 404 回退入口中路径栏的静态文件夹图标。
- 删除对应的 `.address-icon` 死样式。

## 为什么改

该图标没有点击行为、状态表达或辅助信息，只是刷新按钮与面包屑之间的装饰，增加视觉噪声和横向占用。GitFiles 品牌已在工具栏中显示，路径栏由面包屑承担路径表达。

## 涉及文件

`index.html`、`404.html`、`css/style.css`。

- 静态检索确认不存在 `address-icon` HTML/CSS 引用。
