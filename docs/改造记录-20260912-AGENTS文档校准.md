# 改造记录 20260912 AGENTS.md 与仓库实际对齐

## 修改了什么

逐节核对 `AGENTS.md`（1040 行）与仓库当前实际代码，删除不属于本项目的内容，
修正与实现不符的描述。

### 1. 删除不属于本项目的内容

**§23「SY-GSP 专项测试」整节重写**

该节讲的是「Siyuan（思源笔记）→ SY-GSP → Markdown → GitHub」专项测试。
核实结果：`SY-GSP`、`Siyuan`、`思源` 在整个仓库中**只出现在 AGENTS.md 自身**，
README、PROJECT_SPEC、状态总览、任何源码里都没有对应实现或引用——
这是一条**私有下游用法**，不属于本项目。

已重写为通用的「集成与删除语义」，保留其中真正有价值的部分：

```text
23.1 删除语义      删除必须真正落到 Git Tree，不留残留文件（含 base_tree 陷阱说明）
23.2 第三方工具集成 外部工具写入/删除 ↔ 应用内的可见性一致性
23.3 平台间往返     Android ↔ NAS ↔ GitHub，含文件名 Unicode 规范化要求
```

### 3. 补充一处容易被误删的安全件

`workers/github-oauth-token.js` 未被任何模块引用，看起来像死代码，
实际是**上游遗留 OAuth 代理的安全替代件**：它故意拒绝所有请求，
防止旧部署把它当作 token 出口。已写入 §5 并注明「不要删除」。

## 为什么改

两个原因：

1. **不属于本项目的内容混进来了**——AGENTS.md 是给所有 AI Agent 读的操作规范，
   里面写一个私有下游项目的测试流程，会让协作者误以为那是本项目的验收范围。
2. **规范与代码不一致比没有规范更危险**——照着 §12 的路由去实现会直接 404；
   按 §5 的目录结构新增文件会加错地方；以为 GitHub App 已实现会重复造轮子。
