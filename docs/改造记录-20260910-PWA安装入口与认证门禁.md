# 改造记录：PWA 安装入口与认证门禁

## 修改了什么

- 将 PWA 安装入口从登录卡片移动到左侧“添加存储”下方，使用紧凑的侧栏样式。
- 安装按钮在 Edge 未触发 `beforeinstallprompt` 时仍可见，点击后提示 Edge 菜单中的手动安装路径。
- 页面头部继续尽早捕获安装事件，避免 Edge 丢失事件。
- 欢迎页“添加仓库”入口增加 GitHub Worker 会话门禁，未认证时先完成 GitHub 登录，认证失败不会进入仓库选择/创建流程。
- 侧栏 GitHub 仓库入口同样先调用 `/api/me` 验证会话。

## 测试情况

- 前端脚本语法检查通过。
- Git 引擎 35 项测试通过。
- Worker API 13 项测试通过。
- 构建和 `git diff --check` 通过。

## 遗留问题

Edge 是否触发自动安装事件仍由 HTTPS、Manifest、Service Worker 控制状态及浏览器版本决定；未触发时可通过 Edge 菜单“应用”手动安装。
