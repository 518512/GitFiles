# 改造记录：移除 Google 并优化加载

## 修改了什么

- 彻底移除 Google 登录、Google Drive API、GSI 脚本、Google Drive 菜单与配额逻辑。
- 保留本地存储和 GitHub OAuth/仓库操作；旧 Google 入口由无凭据兼容层明确提示已移除。
- 删除 Google 配置变量、权限范围、Service Worker 资源与进度统计项，刷新缓存版本。
- 精简本地/GitHub 跨存储操作分支，减少首屏脚本和无效网络请求。
- 保留 GitHub Git Data 的完整 Tree、Blob 复用、CAS 与冲突处理。
