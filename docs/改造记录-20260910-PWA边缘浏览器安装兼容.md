# 改造记录：PWA Edge 安装兼容

## 修改了什么

- 在 HTML 头部尽早捕获 `beforeinstallprompt`，避免 Edge 在应用脚本初始化前触发事件而丢失安装事件。
- 安装入口不再依赖浏览器一定触发自动安装事件：页面始终显示“安装 GitFiles”按钮。
- Edge 未提供自动安装提示时，点击按钮会给出“菜单 → 应用 → 将此站点安装为应用”的明确指引。
- 增加 Manifest `id`，帮助 Edge/Chromium 稳定识别同一 PWA 应用。

## 使用说明

请使用 HTTPS 或 localhost 打开页面，并刷新一次。Android/平板 Edge 可通过页面安装按钮；如果系统不提供自动提示，请打开 Edge 菜单 → 应用 → 将此站点安装为应用。

## 遗留问题

普通 HTTP 局域网地址通常不满足 Chromium 安装条件；此时只能使用 HTTPS 或 localhost。不同 Edge 版本的菜单名称可能显示为“安装应用”或“添加到手机”。
