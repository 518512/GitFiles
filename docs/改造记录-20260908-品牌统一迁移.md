# 改造记录：全仓品牌由 Storage Hub 统一为 GitFiles

- 日期：2026-09-08
- 关联：`docs/改造记录-20260908-文档双语与CF一键部署.md`（其中"遗留问题"提到 site-config 上游值，本次一并处理）

## 修改了什么

### 用户可见品牌 / 配置（27 个文件）

- `manifest.webmanifest`：`name` / `short_name` / `description` → GitFiles
- `sw.js`：缓存名前缀 `storage-hub-` → `gitfiles-`；`js/app-version.js` 版本戳更新（强制客户端缓存刷新）
- `.github/workflows/pages.yml`：工作流名 → Deploy GitFiles to Pages
- `js/site-config.js`：`name: 'GitFiles'`、开发者 → `MbAIGC`、仓库/主页 → `MbAIGC/GitFiles` 与 `https://mbaigc.github.io/GitFiles/`、`basePath: '/GitFiles'`、上游 Google 验证码置空（注释保留配置说明）
- `js/config.js`：`BASE_PATH` 兜底值 → `/GitFiles`
- `index.html` / `404.html` / `notepad.html`：`<title>`、登录页品牌区（h1/by-line/logo alt）、窗口标题、侧栏、Google 授权提示文案、`DEPLOY_BASE = '/GitFiles'`；**移除上游作者的 google-site-verification meta**（对本站无效）
- `privacy.html` / `terms.html`：品牌、站点 URL、运营者信息、issues 链接更新；责任主体改为 "The GitFiles maintainers"
- `js/githubdisk.js` / `contextmenu.js` / `router.js` / `app.js` / `notepad.js` / `dialog.js`：所有 `SITE.name` 缺失时的兜底品牌文案 → GitFiles
- `serve.py`、`workers/github-oauth-token.js`、`functions/api/github/oauth/token.js`：User-Agent 与注释 → GitFiles；Worker 的 `ALLOWED_ORIGINS` 上游域名 → `https://mbaigc.github.io`
- `assets/logo.svg` / `favicon.svg`：`aria-label` → GitFiles
- `js/register-sw.js`：内部模块名 `StorageHubCache` → `GitFilesCache`

### 有意保留（数据兼容 / 归属，禁止改动）

| 保留项 | 原因 |
|--------|------|
| `storage_hub_*` / `mikus_*` 各 localStorage/IndexedDB 键（disks/users/local_user/app_root/app_version/operation_stats 等） | 改键会导致老用户已连接的存储与配置全部丢失 |
| `window.StorageHub` / `window.MikusDrive` 全局别名 | 公开 API 别名，contextmenu 等调用方在用 |
| `storage-hub-github-oauth` 消息源 / BroadcastChannel 名 | OAuth 弹窗↔主窗口跨页面契约，且受 SW 缓存过渡期影响 |
| `application/x-storage-hub-item` 拖拽 MIME、`storage-hub:notepad-handoff:` 前缀、`data-storage-hub-*` DOM 标记 | 内部契约，用户不可见，改了无收益 |
| `README.md` / 页脚 / 法务页中的 "Storage Hub by Mykhailo Mikus" 及上游链接 | 开源归属（fork 出处），依法与道义保留 |
| `docs/PROJECT_SPEC.md`、`AGENTS.md`、历史改造记录 | 规格与历史事实记录 |

## 为什么改

用户反馈"好多文件里的名称都未更改"：fork 后品牌、站点配置、法务页、工作流描述仍全部指向上游作者（fi3ik-mme / Mykhailo Mikus / storage-hub / 旧域名 / 上游 Search Console 验证码），造成部署站点品牌混乱且验证 meta 无效。
