# 改造记录：澄清构建变量与运行时变量的界面区块

- 日期：2026-09-08
- 关联：`docs/改造记录-20260908-部署变量速查表.md`

## 背景

用户在 Cloudflare Dashboard 看到 "Runtime variables and secrets" 区块，疑问
CONFIG_* 变量应配置在哪里。新版 Workers Builds 界面中构建变量与运行时变量
分属两个区块：Build variables（Settings → Build）与 Runtime variables and
secrets（Settings → Variables and secrets），互不可见。

## 修改了什么

双语 README 方式一步骤 4 改写：明确 CONFIG_*（Text）必须配在 **Build
variables**（构建时唯一可见），GITHUB_CLIENT_SECRET（Secret）配在 **Runtime
variables and secrets**；速查表结论不变，补充界面位置。

## 为什么改

此前"Settings → Variables and Secrets 添加"的表述未区分区块，用户配到
Runtime 区会导致构建读不到、注入静默失效。
