服务条款

最后更新：2026 年 6 月 6 日

本服务条款（以下简称“条款”）适用于你对 GitFiles（https://mbaigc.github.io/GitFiles/）的使用。 GitFiles 是一个用于管理云端和本地文件存储的浏览器客户端，由 MbAIGC 维护，是基于 Mykhailo Mikus 的 Storage Hub 修改的分支项目。 访问或使用应用，即表示你同意本条款。

1. 服务说明

GitFiles 是一个客户端优先的 Web 应用，通过 Cloudflare Worker 连接已授权的 GitHub 仓库。 应用帮助你使用文件管理器界面浏览、整理和操作本地存储与 GitHub 文件。服务按“现状”和“可用”状态提供，不保证持续在线、无错误或提供特定级别的技术支持。GitFiles 不隶属于 GitHub。

2. 使用资格

你必须具备依法同意本条款的资格。使用本应用时，你还必须遵守 GitHub 服务条款以及适用法律。

3. 你的账号和设备

你通过 GitHub 直接登录，应用不会为你创建独立的第三方账号。你负责：

  • 保护 GitHub 账号、设备和浏览器的安全；
  • 审查并批准应用请求的 OAuth 权限；
  • 对你登录期间通过应用执行的文件和仓库操作负责；
  • 确保你对访问、编辑、移动、复制或删除的文件拥有相应权限。

4. 合理使用

你同意不会：

  • 违反适用法律或第三方权利使用应用；
  • 干扰、逆向工程、攻击或滥用 GitHub、Cloudflare API 或应用；
  • 使用应用传播恶意软件，或访问你无权访问的数据；
  • 冒充他人或虚假描述身份；
  • 规避应用的权限检查、并发冲突保护或安全限制。

5. GitHub 与本地数据

应用代表你请求访问 GitHub 仓库；本地文件仅保存在你的设备。通过应用创建、修改、删除、复制、移动或共享的内容会影响你的 GitHub 数据。 GitHub 删除不会进入 GitHub 回收站，而是通过 Git 提交从分支当前树中永久移除对应路径；请在确认删除前仔细检查操作。 特别是在跨账号、跨存储或多设备操作时，应确认目标位置和权限。

6. 无担保

在法律允许的最大范围内，应用按“现状”和“可用”状态提供，不作任何明示或默示担保，包括适销性、特定用途适用性和不侵权担保。 我们不保证应用始终不中断、无错误、及时、安全或不会发生数据丢失。涉及重要数据时，你应自行保留备份。

7. 责任限制

在法律允许的最大范围内，GitFiles 维护者和贡献者不对因使用或无法使用应用而产生的任何间接、附带、特殊、后果性或惩罚性损害负责， 也不对数据、利润或商誉损失负责，即使已被告知可能发生此类损害。

8. 开源软件

应用源代码可能公开在项目仓库中。源代码的使用、修改和分发可能受仓库中包含的许可证约束；该许可证与本托管服务条款分别适用。

9. 服务或条款变更

我们可以随时修改应用或本条款。重大变更会通过更新“最后更新”日期体现。变更生效后继续使用应用，即表示你接受修订后的条款。

10. 终止使用

你可以随时退出应用，并在 GitHub 账号设置中撤销授权。我们也可以在任何时候停止、限制或调整托管应用，恕不另行通知。

11. 隐私

你对应用的使用还受我们的隐私政策约束，隐私政策说明应用如何处理信息。

12. 联系方式

关于本条款的问题，可以通过项目仓库提交 Issue： github.com/MbAIGC/GitFiles/issues。
